# Notes Planner

A personal notes and planner web app — write notes and manage a calendar with scheduled events, behind a simple email-based login.

## Status

Work in progress — first full project built from scratch.

**Done:**
- Login page (email input, client-side validation)
- Language switcher UI (English/Ukrainian — not functional yet)

**Planned:**
- Email verification code flow
- Notes section
- Calendar section
- Node.js + Express backend with SQLite database
- Dark/light theme toggle
- Full language switching

## Tech stack

- HTML, CSS, JavaScript (vanilla, no frameworks)
- Backend (planned): Node.js, Express, SQLite

## Running locally

Open `index.html` in your browser — no build step required yet.
